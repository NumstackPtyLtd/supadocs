Acme is a platform for building modern applications. It provides APIs, SDKs, and infrastructure so your team can ship faster.

## Why Acme

- **One API** for everything: auth, data, events, and more
- **Type-safe SDKs** in TypeScript, Python, and Go
- **Built-in compliance**: SOC 2, GDPR, HIPAA

## How it works

<Steps>
  <Step title="Create an account">
    Sign up at the Acme dashboard and create your first project.
  </Step>
  <Step title="Get your API key">
    Navigate to Settings and copy your API key.
  </Step>
  <Step title="Make your first request">
    Use the SDK or call the REST API directly.
  </Step>
</Steps>

<Note>
All API requests are authenticated. See the authentication guide for details.
</Note>
